# dorian v1.4.1 — Documentation and package metadata

A patch release. It changes documentation, package metadata, the generated README hero and the PyPI
long description. **No behaviour changes**: the checker, binding, fold, warrant format and exit codes
are the same as in v1.4.0, and `src/` changes only in its version string.

## What changed

### Documentation
- The README opens with the recorded httpx example, labels the benchmark historical, and keeps the
  runnable "Try it" recipe, which now starts from a fresh virtual environment and installs
  `dorian-vwp==1.4.1`. The synthetic benchmark numbers cite `docs/BENCHMARK_v0.7.0.md` in the same
  sentence, and the project name is lowercase throughout.
- `docs/REAL_CATCH_LOG.md` adds a `retrospective` outcome. The httpx entry uses it: the replay ran
  after the upstream change had merged, so it shows detection, not a prevented defect.
- `docs/releases/v1.4.0.md` lists the `loop preflight --format` values the CLI accepts
  (`json|md|text`) and uses the "Deferred interface" heading of the published notes.
- Release notes for v1.0.2 and v1.2.0 credit AI-assisted review without naming a model.
- `CONTRIBUTING.md` is new: setup, checks, the README-example test, and the project's rules.

### Samples
- The generated hero (`docs/assets/hero-{light,dark}.svg`) reads "Claims become executable checks
  sealed beside the code; revalidate re-runs affected checks." Both files are regenerated by
  `docs/assets/src/make_figures.py`.
- Action snippets in the README and docs pin `ajaysurya1221/dorian/action@v1.4.1`.

### Package metadata and PyPI description
- The summary reads: "Turn claims about code into executable checks and revocable warrants,
  re-checked as code changes with no model calls during verification."
- The licence is the SPDX expression `Apache-2.0` with `license-files = ["LICENSE"]` (hatchling
  1.27 or later). Classifiers list Python 3.11, 3.12 and 3.13, the versions CI tests.
- The PyPI long description is built from `README.md` by `hatch-fancy-pypi-readme`: links and
  images that are relative in the repository point to GitHub URLs pinned to `v1.4.1`, and the hero
  is the light SVG. `README.md` on GitHub keeps its relative paths.

## What did not change

Checkers and checker grammar, binding, fold policy, warrant format, exit codes, CLI commands and
the zero-runtime-dependency core are unchanged from v1.4.0. Existing warrants need no migration.

## Benchmark

The benchmark figures are from the v0.7.0 synthetic benchmark (240 authored pairs). The last
recorded rerun was at v1.2.0; they were not re-run for this release, and they are specific to the
authored fixtures.
